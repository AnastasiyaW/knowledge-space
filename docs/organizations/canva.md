## What it is

Canva Magic Layers is a Canva AI feature that turns a static image into an editable design.

- Text: restores editable text.
- Layers: separates objects and background into distinct layers.
- Layout: adjusts position, size, font, color, and format.

At launch it was a public beta only in the US, UK, Canada, and Australia; Canva now claims global access through the Gemini and ChatGPT apps. This is a practical step between image generation and manual retouching, not a replacement for an original layered file.
