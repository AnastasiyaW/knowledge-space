## What it is

OpenAI — поставщик ChatGPT, ChatGPT Work, Codex и API для частных пользователей, команд и разработчиков; по охвату это конкурент связкам Anthropic Claude + API и Google Gemini + Vertex AI, а не один чат-бот. Возможности: - ChatGPT — диалоги, поиск, анализ файлов, изображения и голос; - Work — длительные задачи с приложениями, файлами, браузером и готовыми документами; - Codex — работа с репозиториями, терминалом, тестами и ревью; - API — Responses, инструменты, компьютерное управление, поиск, мультимодальность и агентные процессы. Мера/лимит: GPT‑6 Astra имеет контекст 1 050 000 токенов, вывод до 128 000 токенов и срез знаний 30 апреля 2026 года; стандартная цена API — $10 за миллион входных и $50 за миллион выходных токенов, а доступ 4 сентября 2026 года ещё разворачивается по тарифам и продуктам. Вердикт: Chat подходит для короткого взаимодействия, Work — для длительного результата, Codex — для репозитория, Responses API — для собственного продукта; модель, инструменты и полномочия нужно выбирать по измеренному качеству и риску операции.

## How to use this

As of 2026-06-26, practitioners should choose OpenAI models and platform features by the exact documented release and API capability, and revalidate access, pricing, safety-testing status, and compatibility before deployment instead of assuming behavior carries across generations.

1. OpenAI ChatGPT: войдите через web или desktop и выберите Chat для короткого диалога, Work для длительного результата либо Codex для кода.
  — <https://learn.chatgpt.com/docs/quickstart>
2. OpenAI Work: создайте задачу, приложите исходные материалы, укажите результат и ограничения, затем отслеживайте действия, отвечайте на вопросы и подтверждайте существенные операции.
  — <https://learn.chatgpt.com/docs/get-started-with-work>
3. OpenAI Codex: установите CLI, войдите в аккаунт, запустите его из корня Git-репозитория и сохраняйте контрольные точки перед агентными изменениями.
  — <https://learn.chatgpt.com/docs/codex/cli>
4. OpenAI API: создайте ключ, храните его в переменной окружения, установите официальный SDK и выполните первый запрос через Responses API.
  — <https://developers.openai.com/api/docs/quickstart>
5. OpenAI API: выберите Astra для наиболее сложной сквозной работы, Terra для баланса качества и цены, Luna для дешёвого массового потока; сначала проверьте доступ своего тарифа и региона.
  — <https://developers.openai.com/api/docs/models>
6. OpenAI Responses: перенесите новые и старые агентные процессы на Responses, подключая web search, file search, computer use или собственные функции только по необходимости.
  — <https://developers.openai.com/api/docs/guides/migrate-to-responses>
7. OpenAI Evals: соберите представительный набор примеров, задайте проверяемые критерии и сравните модели, промпты и настройки до обновления production-потока.
  — <https://developers.openai.com/api/docs/guides/evals>
8. OpenAI agents: оставьте рабочую директорию границей по умолчанию, настройте сеть и подтверждения и выдавайте полный доступ только для явно доверенной задачи.
  — <https://learn.chatgpt.com/docs/permission-modes>

## Best practices

- OpenAI Astra: явно задавайте результат, приоритет инструкций, допустимую самостоятельность и критерий проверки; проверяйте skills и AGENTS.md, потому что модель чувствительнее к содержащимся там указаниям.
  — <https://developers.openai.com/api/docs/guides/latest-model?model=gpt-6-astra>
- OpenAI API: выбирайте модель и reasoning effort по собственным evals, а не по максимальному классу; Astra не поддерживает effort=none, а tool calling для неё требует Responses API.
  — <https://developers.openai.com/api/docs/guides/latest-model?model=gpt-6-astra>
- OpenAI Prompt Caching: держите неизменные инструкции и примеры в начале запроса, динамические данные — в конце, и измеряйте cache hits, стоимость и задержку.
  — <https://developers.openai.com/api/docs/guides/prompt-caching>
- OpenAI agents: совмещайте sandbox и подтверждения; отдельно подтверждайте внешние отправки, покупки, удаление и расширение доступа, а full access не используйте как обычный режим.
  — <https://learn.chatgpt.com/docs/agent-approvals-security>
- OpenAI connectors: подключайте только нужные репозитории и источники; GitHub в ChatGPT используйте для чтения и исследования, а запись и push выполняйте через Codex с отдельными полномочиями.
  — <https://help.openai.com/en/articles/11145903-connecting-github-to-chatgpt-deep-research>
- OpenAI Deep Research: задавайте разрешённые источники, проверяйте предложенный план, корректируйте исследование по ходу и открывайте первоисточники за цитатами перед использованием результата.
  — <https://help.openai.com/en/articles/10500283-deep-research>
- OpenAI Work: передавайте реальные материалы, контекст, ограничения, формат результата и правила ревью вместо общей просьбы; проверяйте готовый артефакт и его доказательства.
  — <https://learn.chatgpt.com/docs/get-started-with-work>
- OpenAI Astra: не считайте внутреннее рассуждение достаточным аудитом — сохраняйте границы полномочий, внешние проверки и журналы действий, поскольку официальная оценка выявила ухудшение monitorability в состязательных условиях.
  — <https://openai.com/index/safety-overview-gpt-6-astra/>
