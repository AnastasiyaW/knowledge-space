# Microsoft

## What it is

Microsoft is a company whose current practitioner-facing AI products in this line are Microsoft 365 Copilot for document work and Microsoft Designer for personal visual work.

- **Copilot in Word** drafts, rewrites, summarizes, and answers questions about documents using selected work context.
- **Microsoft Designer** creates and edits graphics from text; Word image creation uses Designer’s Image Creator and DALL-E 3.

## Development line

- **2022-10-22 — Microsoft introduced Image Creator for limited market testing.** Image Creator entered testing in selected markets. This was an early limited-availability step in Microsoft’s public rollout of generative-image functionality.
- **2022-10-26 — Microsoft expanded Image Creator availability through Bing.** Image Creator was available in some countries through Bing, while Edge availability was still forthcoming. This moved the product from limited testing toward a broader regional rollout.
- **2024-05-23 — Microsoft Build 2024 marked a public AI platform milestone.** Three video resources associated with Microsoft Build 2024 support treating the conference as a material public platform milestone. They do not establish any unverified individual announcement.
- **2025-05-04 — Microsoft Design documented an advertisement made with generative AI.** Microsoft Design documented its use of generative AI to create an advertisement. The work documents practical creative use of generative AI, not a new product release.

## What changed

- **2022-10-22** — Image Creator was in a limited preview in selected markets. The documented inputs were prompt, context, and style, with DALL-E 2 underneath.
- **2022-10-26** — Image Creator was moving into the Edge sidebar for the same markets. It was still a Bing/Edge feature, not a general creative suite.
- **2023-01-09** — GPT was reportedly being tested in Word and Outlook for text completion, email search, and writing suggestions. Public rollout remained unknown.
- **2023-03-16** — Microsoft formally introduced Microsoft 365 Copilot, connecting LLMs, Microsoft Graph/business data, and Word, Excel, PowerPoint, Outlook, and Teams.
- **2024-05-23** — Build 2024 extended the line toward Team Copilot and Copilot Studio agents, connectors, and extensions. Several announced capabilities were preview or Early Access.
- **2025-05-04** — Microsoft’s visual design team described using generative tools for rapid concept and storyboard work. The ad used human-controlled compositing and selective live action.
- **2026-09-04** — The current practical routes are separate: Copilot in Word for document work and Designer for personal design and image creation. Word’s image feature now uses Designer’s Image Creator with DALL-E 3.

## How to use this

From 2022-10-26 onward, Microsoft’s generative-image capabilities should be treated as a staged, region-limited rollout. Practitioners should verify current product and regional availability before relying on them.

1. Confirm that Copilot is included in the Microsoft 365 subscription and enabled by the organisation before starting in Word.
  — <https://support.microsoft.com/en-us/word/welcome-to-copilot-in-word>
2. For text work, open a Word document. Select the Copilot Dynamic Action Button, state the desired outcome, and point Copilot to the source material.
  — <https://support.microsoft.com/en-us/word/welcome-to-copilot-in-word>
3. Review, reject, or refine the generated Word output before accepting it. Shared-document changes remain in preview until approval.
  — <https://support.microsoft.com/en-us/word/welcome-to-copilot-in-word>
4. For a personal visual, sign in to Designer. Open Create with AI, describe the image, select Generate, choose the closest result, then edit or download it.
  — <https://support.microsoft.com/en-gb/topic/welcome-to-microsoft-designer-6cd168f3-1cf0-478e-bd75-31d6526d2504>
5. To insert a generated visual into Word, place the cursor. Open the Copilot pane, describe the image, add a result with the plus control, then format or resize it.
  — <https://support.microsoft.com/en-us/word/copilot/generate-images-for-your-documents-with-copilot-in-word>

## Best practices

- State the desired outcome, then add source material, length, format, and tone. Refine with follow-up prompts instead of treating the first draft as final.
  — <https://support.microsoft.com/en-us/word/welcome-to-copilot-in-word>
- For Word images, specify subject, location or activity, and visual style. Image generation is not a stock-image search.
  — <https://support.microsoft.com/en-us/word/copilot/generate-images-for-your-documents-with-copilot-in-word>
- Inspect and approve Copilot’s shared-document preview before collaborators receive any generated change.
  — <https://support.microsoft.com/en-us/word/welcome-to-copilot-in-word>
- Use personal Designer only for non-commercial work. Its prompts and input images are abuse-monitored and collected under Microsoft’s stated terms, so assess that boundary before entering sensitive material.
  — <https://support.microsoft.com/en-us/designer/frequently-asked-questions-about-microsoft-designer>
- Inspect lettering and spelling in every generated image. Designer warns that text may be in the wrong language or misspelled.
  — <https://support.microsoft.com/en-us/designer/frequently-asked-questions-about-microsoft-designer>
- For moving people, use generated visuals for quick or limited-motion shots. Shoot detailed hands or complex motion live, and manually correct frames.
  — <https://microsoft.design/articles/we-made-an-ad-with-generative-ai/>
