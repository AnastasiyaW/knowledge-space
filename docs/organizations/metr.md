## What it is

METR model evaluation is independent safety testing and measurement advice for frontier AI labs, regulators and research teams. It does four things:

- measures task completion over long agent time horizons
- audits autonomous software engineering skill
- probes whether a model can improve itself recursively
- detects situational awareness inside evaluation environments

The limits are benchmark saturation, evaluation gaming, and static test suites that cannot rule out fast capability jumps during deployment. So it works as an empirical check on the assumption that autonomous agents are safe.

## What changed

METR first set standard agent evaluation tasks for short-horizon autonomous replication and cybersecurity. The protocols then grew to track multi-hour and multi-day research engineering benchmarks across partner labs. The method has since moved to monitoring recursive self-improvement. It also alerts the industry when capabilities grow faster than the tools that verify safety.
