# Yandex

## What it is

Yandex is a set of separate services for AI and media.

- **Alice AI:** works with text, images, and files.
- **Yandex Browser:** translates and voices videos.
- **Shedevrum:** creates images, videos, clips, and text.
- **Yandex Music:** offers Neuro Music for listening.

These are not one product. Features and terms depend on the service. Choose a service for each task instead of applying one service’s capabilities across Yandex.

## How to use this

Treat Shedevrum’s site and mobile listings dated 2023-04-05 as Yandex public-product touchpoints. Verify current availability and capabilities separately.

1. Open Alice AI, sign in for new chats and history, then enter a task or attach a file.
  — [Alice AI](https://alice.yandex.ru/)
2. In Yandex Browser, hover over a foreign-language video, select “Перевести и озвучить” (“Translate and voice”), and wait for the translation to be ready.
  — [Browser translator settings](https://yandex.ru/support/browser/ru/search-and-browse/translators-settings)
3. Open Shedevrum; its current web sign-in redirects to Yandex ID authorization.
  — [Shedevrum](https://shedevrum.ai/)
4. In Shedevrum, choose “Изображение” (“Image”) and a model, describe the result, press “Создать” (“Create”), then edit, publish, or download a version if needed.
  — [Shedevrum image creation](https://yandex.ru/support/shedevrum/ru/picture/create)
5. For Neuro Music, open the Collections section in Yandex Music and go to Neuro Music settings.
  — [Yandex Music collections](https://www.yandex.ru/support/music/ru/collection/collection_management)

## Best practices

- For video translation, first check the supported language, platform availability, and the 4-hour limit. If the button is missing, enable it in settings and update Browser.
  — [Browser translator settings](https://yandex.ru/support/browser/ru/search-and-browse/translators-settings)
- For English-language videos, choose regular voices when speed matters and live voices when intonation matters. Live voices require an account sign-in.
  — [Browser translator settings](https://yandex.ru/support/browser/ru/search-and-browse/translators-settings)
- In Shedevrum, choose the model for the task and write a specific prompt with objects, properties, and composition. Change the description iteratively instead of expecting an exact result on the first run.
  — [Shedevrum image creation](https://yandex.ru/support/shedevrum/ru/picture/create)
- Check the Shedevrum result before final use. The help says generations are first created in low quality and improve in quality when published.
  — [Shedevrum image creation](https://yandex.ru/support/shedevrum/ru/picture/create)
