## What it is

Runway is a cloud platform for filmmakers, creative teams and developers, competing with Adobe Firefly/Premiere on the creative side and Replicate on the API side. It now has three surfaces: Creative for generating and editing video, images and audio; Dev for APIs, MCP and multi-model routing; and Robotics for simulation tooling. Gen-4.5 is the current Runway video model: web generations are 2–10 seconds, 720p, 24/25 fps and 12 credits per second; Aleph 2.0 edits 2–30-second clips, while Act-Two transfers a recorded performance to a character for up to 30 seconds. Use Runway as an integrated shot-production system, not as a one-prompt finished-film generator.

## How to use this

As of 2025-07-18, practitioners should not change production workflows from this sealed line alone. Use it to locate the Gen-2, longer-duration video, and Lionsgate-partnership milestones, then verify current first-party Runway documentation before relying on any capability, availability, or partnership implication.

1. Open the Runway web app and create or enter a workspace.
  — <https://app.runwayml.com/>
2. Choose the surface: Tools for explicit model settings, Apps for task-specific workflows, Agent for conversational multi-shot work, or Workflows for reusable node pipelines. Each creates a Session that keeps outputs together.
  — <https://help.runwayml.com/hc/en-us/articles/37425232841875-Getting-Started-with-Generative-Video>
3. For a new shot, choose Gen-4.5 Text to Video for an unanchored idea or Image to Video when composition and identity must start from a specific frame. Set aspect ratio, 2–10-second duration and 24 or 25 fps, then generate and iterate.
  — <https://help.runwayml.com/hc/en-us/articles/46974685288467-Creating-with-Gen-4-5>
4. Build reusable characters, products or locations with Gen-4 Image References; name references, invoke them with @ and use up to three in one generation.
  — <https://help.runwayml.com/hc/en-us/articles/40042718905875-Creating-with-Gen-4-Image-References>
5. For character acting, open Apps > Performance Capture with Act-Two, upload a driving-performance video plus a character image or video, choose gesture handling and generate.
  — <https://help.runwayml.com/hc/en-us/articles/42311337895827-Performance-Capture-with-Act-Two>
6. For existing footage, open Edit Studio, upload the clip, edit a representative keyframe, preview the change and let Aleph 2.0 propagate it through the selected shot or range.
  — <https://help.runwayml.com/hc/en-us/articles/51683104370451-Creating-with-Edit-Studio>
7. Assemble and trim accepted shots in Agent or Studio. For editorial or VFX delivery, choose MP4, ProRes or PNG sequence before generation; ProRes and PNG sequence require an eligible plan and cannot be retrofitted to an existing generation.
  — <https://help.runwayml.com/hc/en-us/articles/54396547993491-Exporting-Videos-in-ProRes-and-PNG-Sequence-Formats>
8. For automation, create a Runway Dev account and API key, use the SDK or REST endpoint, submit the generation as an asynchronous task and wait for its output or explicit failure.
  — <https://docs.dev.runwayml.com/guides/using-the-api/>

## Best practices

- Choose the control mode from the material you already have: text-to-video for exploration, image-to-video for a locked first frame, and video-to-video/Edit Studio when original motion and framing matter most.
  — <https://runway.com/resources/how-ai-video-generation-works>
- Start with the smallest clear prompt, change one element per iteration and describe what should happen in positive, literal language. JSON formatting itself adds no accuracy.
  — <https://help.runwayml.com/hc/en-us/articles/47313698911891-Introduction-to-Prompting>
- For image-to-video, let the image supply subject, composition, lighting and style; use text mainly for subject, environment and camera motion. Remove blur, malformed anatomy and conflicting implied-motion cues before animating.
  — <https://help.runwayml.com/hc/en-us/articles/48324313115155-Image-to-Video-Prompting-Guide>
- Describe camera work with established shot, angle, direction and speed terms. Give each clip one directed beat and control cuts in the timeline instead of asking one generation for an entire sequence.
  — <https://runway.com/resources/ai-camera-prompts>
- For consistent characters, start with an evenly lit, neutral reference; save and name it, then add only the references required for the shot.
  — <https://help.runwayml.com/hc/en-us/articles/40042718905875-Creating-with-Gen-4-Image-References>
- For Act-Two, keep the performer visible at least from the waist up, preserve clear eyes and mouth, avoid cuts and match the character-video duration to the performance. Use a character image when gesture transfer matters; use character video when existing camera and environmental motion must remain.
  — <https://help.runwayml.com/hc/en-us/articles/42311337895827-Performance-Capture-with-Act-Two>
- For Aleph 2.0, state one action verb and the requested transformation, preview the keyframe before propagation and limit the edited range when only part of the clip needs work.
  — <https://help.runwayml.com/hc/en-us/articles/52150503729171-Aleph-2-0-Prompting-Guide>
- Keep original exports and their C2PA metadata, and disclose synthetic footage where provenance matters. Human visual inspection is not a dependable authenticity check.
  — <https://runway.com/research/theturingreel>

## Superseded by this

- 2025-05-11 — Gen-2 was fully deprecated. Its Motion Brush, Motion Slider, Director Mode and 18-second-extension instructions are no longer usable; Runway directs users to Gen-4.5 and prompt-based motion control.
- 2025-04-30 — Gen-4 References superseded most day-to-day 2022 AI Training guidance for recurring characters, locations and objects; references work without running a custom-training job.
- 2025-07-17 — Act-Two superseded Act-One as Runway’s supported performance-capture workflow.
- 2025-12-11 — Gen-4.5 superseded Gen-4 as the quality-first Runway video model. Gen-4 and Gen-4 Turbo remain older, cheaper or faster alternatives where available.
- 2026-05-21 — Aleph 2.0 in Edit Studio superseded the original 2025 Aleph workflow and increased the supported edit window to 30 seconds.
