# NotebookLM

## What it is

NotebookLM, now called Gemini Notebook, is Google’s workspace for students, analysts and teams working strictly from selected documents.

- Chat: answers against selected sources with inline citations.
- Studio: creates reports, data tables, flashcards, quizzes, mind maps, audio/video overviews, infographics and slide decks.
- Limits: 50 sources per free notebook, up to 500,000 words or 200 MB each, with compute-based usage that varies by plan.

## What changed

- 2023-07-12 — NotebookLM launched from Project Tailwind as a small U.S. Google Labs rollout to answer from selected documents with citations.
- 2024-05-14 — I/O previewed Audio Overviews, using Gemini to turn uploaded sources into an interactive verbal discussion.
- 2025-05-19 — iOS and Android apps added offline Audio Overviews, host interaction and share-sheet source capture.
- 2025-07-30 — Video Overviews and an upgraded Studio allowed saving multiple outputs instead of one artifact per type.
- 2025-08-25 — Video Overviews expanded to 80+ languages, with longer Audio Overviews in those languages.
- 2026-03-04 — Cinematic Video Overviews added an English, 18+ Google AI Ultra format built with Gemini 3, Nano Banana Pro and Veo 3.
- 2026-04-08 — Notebooks synced between Gemini and NotebookLM, linking project structure and chat context across apps.
- 2026-07-03 — Short Video Overviews were announced as ~60-second vertical source explanations, with the underlying announcement dated 2026-06-30.
- 2026-07-16 — The product was renamed Gemini Notebook, added a secure cloud computer for native code execution on eligible tiers, and broadened its Google ecosystem role.
- 2026-09-02 — Usage moved to compute-based limits that factor prompt and feature complexity, model, chat length and quota.

## How to use this

From 2025-07-30, practitioners should consider Video Overviews and Studio when selecting NotebookLM outputs and workspace workflows, subject to availability in their account.

1. Open notebook.google.com, create one notebook per project, and add the source set that defines the answers.
  — <https://support.google.com/gemininotebook/answer/16206563>
2. Import only material you may use: supported files, Google content, web URLs, public-captioned YouTube videos, or selected Gemini chats.
  — <https://support.google.com/gemininotebook/answer/16215270?co=GENIE.Platform%3DDesktop&hl=en-GB>
3. In Chat, select the relevant sources, ask a specific question, and open each inline citation to read its quoted evidence in context.
  — <https://support.google.com/gemininotebook/answer/16179559?hl=en&ref_topic=16164070>
4. In Studio, generate a report or data table from the source set and export it to Docs or Sheets when appropriate.
  — <https://support.google.com/gemininotebook/answer/16206563>
5. For visual review, create a Video Overview and set its format, language and steering prompt before generating.
  — <https://support.google.com/gemininotebook/answer/16454555?hl=en&ref_topic=16164070>
6. If you also work in Gemini, use its cross-app notebook view for continuity but keep strict source-grounded conclusions in Gemini Notebook.
  — <https://support.google.com/gemininotebook/answer/17003757?hl=en&ref_topic=16164070>

## Best practices

- Keep one bounded project per notebook: notebooks are independent and cannot access one another’s information.
  — <https://support.google.com/gemininotebook/answer/16206563>
- Select relevant sources and ask narrow questions; inspect cited quotes in context rather than trusting smooth answers.
  — <https://support.google.com/gemininotebook/answer/16179559?hl=en&ref_topic=16164070>
- Treat generated video as a study aid, not final evidence: voices and visuals can glitch or misstate facts.
  — <https://support.google.com/gemininotebook/answer/16454555?hl=en&ref_topic=16164070>
- Treat sharing as source-data access: viewers can read shared sources, and Chat View does not fully revoke that access.
  — <https://support.google.com/gemininotebook/answer/16206563>
- Keep Gemini and Gemini Notebook grounding separate: Gemini Notebook relies strictly on sources, while Gemini can access search and tools.
  — <https://support.google.com/gemininotebook/answer/17003757?hl=en&ref_topic=16164070>
- Plan around variable, compute-based quotas: current limits can refresh every five hours until the weekly limit.
  — <https://support.google.com/gemininotebook/answer/17670842?hl=en&ref_topic=16164070>
- Let Video Overviews run asynchronously and return later: generation can take more than 30 minutes.
  — <https://support.google.com/gemininotebook/answer/16454555?hl=en&ref_topic=16164070>
