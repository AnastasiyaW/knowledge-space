## What it is

Komi Store (formerly GitHub Store) is a Kotlin Multiplatform release browser and installer.

- Asset discovery: finds projects with installable assets.
- Package downloads: gets platform-matched APK, EXE, DMG, AppImage and DEB packages.
- Update tracking: monitors releases and blocks APKs if the Android signing key changes.

- Treat the store as release discovery rather than a security review. Verify the publisher and asset before running any binary.
  — <https://github.com/komi-store/komi-store>
- Check the Android certificate fingerprint and compare desktop installer digests against the published release assets.
