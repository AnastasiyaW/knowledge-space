## How to use this

Use the dated product line when choosing an interaction path: from 2023-09-25, plan for visual, audio, and spoken interaction; from 2024-04-02, include DALL·E image editing where appropriate; from 2024-12-21, evaluate phone access; and from 2025-07-30, use Study Mode for guided learning workflows.

1. Open chatgpt.com or the official mobile app, select New chat, state your task, and send it.
  — <https://help.openai.com/en/articles/12677804-what-is-chatgpt-faq>
2. Give the goal, key context, desired output, and constraints; review the answer, then refine the prompt.
  — <https://help.openai.com/en/articles/10032626-how-do-i-prompt-chatgpt-effectively>
3. For time-sensitive questions, select the web-search icon or use /Search, then open the cited sources.
  — <https://help.openai.com/en/articles/12677804-what-is-chatgpt-faq>
4. For images, select Images or upload a file; for a local edit, select the area and describe the change.
  — <https://help.openai.com/en/articles/11084440-chatgpt-images>
5. For a spoken session, select Voice, grant microphone access, choose an available option, and start speaking.
  — <https://help.openai.com/en/articles/20001274>
6. For learning, choose Tools → Study and learn, state your goal and level, then work through its questions.
  — <https://openai.com/index/chatgpt-study-mode/>
7. For a one-off private context, start a Temporary Chat and choose personalized or non-personalized behavior before sending content.
  — <https://help.openai.com/en/articles/8914046-temporary-chat-faq>

## Best practices

- Make prompts clear, specific, and contextual; iterate after inspecting the first result.
  — <https://help.openai.com/en/articles/10032626-how-do-i-prompt-chatgpt-effectively>
- For important, date-sensitive, time-sensitive, or location-sensitive claims, verify the result and give exact dates, time zones, or locations when relevant.
  — <https://help.openai.com/en/articles/20001274>
- Use Search for live information, then inspect the cited pages rather than treating the generated answer as the source.
  — <https://help.openai.com/en/articles/12677804-what-is-chatgpt-faq>
- Before sharing sensitive material, review Data Controls or use a Temporary Chat; temporary chats can still be retained for up to 30 days for safety.
  — <https://help.openai.com/en/articles/7730893-chatgpt-shared-links-faq>
- For image edits, name the target area and inspect the output: selection highlights are not always exact and edits can extend outside them.
  — <https://help.openai.com/en/articles/11084440-chatgpt-images>
