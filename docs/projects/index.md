# Projects

One page per tool, model or product the news conveyor follows.

## What a project page holds

- A dated development line: each event with its date, what changed, and the link it came with.
- What the project is today, for a practitioner, and how to use it, step by step with sources.
- Best practices experienced users recommend, each with its source.
- What became obsolete, dated - the authority for "do not follow this anymore".
- What remains unknown, stated as unknown rather than guessed.
- A short agent brief at the end for tools that read the page programmatically.

## How pages are made

Pages arrive from the conveyor's reviewed proposals and the research pass on each development
branch. A page whose present state is not yet researched says so instead of guessing; a later
research pass fills it in and dates its supersedes.
