# Runway Gen-3 Alpha

**Development line:** `project:runway-gen-3-alpha` · thread `runway-gen-3-alpha`  
**Last event:** 2024-06-18 · 1 dated since 2024-06-18 · **Researched:** 2026-09-04 · confidence: high

## What it is

Runway Gen-3 Alpha was Runway’s 2024 text-to-video and image-to-video model for creators making short controlled shots from prompts or a source image. It is retired. Gen-4.5 is the current replacement for both generation modes. Animate Frames and Aleph 2.0 replace its keyframe and video-edit workflows.

## How to use this

From 2024-06-18, treat Gen-3 Alpha as a distinct Runway product line. Verify its current capabilities and access terms before choosing it for production work.

1. Do not start a new Gen-3 Alpha job: select Gen-4.5 for text-to-video or image-to-video generation instead.
  — <https://docs.dev.runwayml.com/api-details/api_changelog/>
2. For a shot that begins from an image, use Gen-4.5 image-to-video; for a prompt-only shot, use Gen-4.5 text-to-video.
  — <https://docs.dev.runwayml.com/api-details/api_changelog/>
3. For keyframe animation or editing an existing clip, move the workflow to Animate Frames or Edit Studio Aleph 2.0 rather than Gen-3 Alpha.
  — <https://help.runwayml.com/hc/en-us/articles/30586818553107-Gen-3-Alpha-Prompting-Guide>

## Best practices

- Treat Gen-3 Alpha prompting guidance as historical only. Migrate active work rather than depending on a retired model.
  — <https://help.runwayml.com/hc/en-us/articles/30586818553107-Gen-3-Alpha-Prompting-Guide>
- When reproducing older Gen-3 work, retain the original prompt, input asset and control settings, because Gen-4.5 is a replacement rather than the same model.
  — <https://runway.com/research/introducing-gen-3-alpha>
- Use reference images and instructions when cross-shot character, object or location consistency matters. This is the workflow Gen-4 introduced after Gen-3 Alpha.
  — <https://runway.com/research/introducing-runway-gen-4?iframe=yes>
