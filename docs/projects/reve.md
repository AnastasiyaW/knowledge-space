## What it is

Reve is a direct alternative to Midjourney and Adobe Firefly for browser image generation and editing.

- Conversational creation to generate images in chat.
- Reference collections to guide style and character consistency across work.
- Object editing to modify specific elements.
- Layers and effects to adjust visual composition.
- Reframe to adjust camera framing.
- Video generation through Veo from text prompts or frames.

Native 4K output is rated at 16 megapixels; video is available globally to Pro subscribers. It fits interactive visual work in the web application, but not new API integrations.

## How to use this

As of 2026-02-25, verify Reve workflow assumptions against current release documentation before relying on them. This update documents a versioned release, not operational details.

1. Open Reve and enter the workspace for creation, images, and albums.
  — <https://help.reve.com/hc/en-us/articles/46800570058772-Finding-your-way-around>
2. Describe the task in plain language in chat and submit the prompt.
  — <https://help.reve.com/hc/en-us/articles/46776083658132-Creating-images-in-chat>
3. Pick a good result, add it back to chat, and refine lighting, composition, or content while keeping the original.
  — <https://help.reve.com/hc/en-us/articles/46776083658132-Creating-images-in-chat>
4. Add images and saved reference collections for a consistent style; use the editor and object operations for targeted edits.
  — <https://app.reve.com/>
5. For video, select the video tool in chat, then provide a text prompt or starting and ending frames.
  — <https://help.reve.com/hc/en-us/articles/46799418938900-Video-creation>

## Best practices

- Iterate in one chat: refine a selected generation instead of starting from scratch each time, so the source image stays preserved.
  — <https://help.reve.com/hc/en-us/articles/46776083658132-Creating-images-in-chat>
- Save references across projects to maintain style, character, or mood.
  — <https://help.reve.com/hc/en-us/articles/46776083658132-Creating-images-in-chat>
- Put only persistent requirements like color palette into Custom instructions; keep single-generation requirements in the prompt.
  — <https://help.reve.com/hc/en-us/articles/46798449634452-Custom-instructions>
- Do not build new integrations on Reve API: the service confirms the API is closed.
  — <https://help.reve.com/hc/en-us/articles/46837930295316-Reve-API>
