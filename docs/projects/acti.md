# ACTI

## What it is

ACTI — мобильная клавиатура для людей, которым нужны поиск, перевод, ссылки на встречи и подключённые сервисы без переключения приложений. Возможности: удержание Acti Bar для действия, привязка Skills к клавишам, создание Skills обычным языком, приватная или публичная публикация в Skill Hub. Ограничение: запуск Skill передаёт только настроенный входной текст и может обращаться к AI-провайдерам либо подключённым инструментам. Вердикт: подходит для коротких повторяемых мобильных действий, но требует осознанно настроить доступы и проверять результат перед отправкой.

## How to use this

As of 2026-07-01, practitioners should treat openacti.com and its linked X download endpoint as candidate official ACTI access points, while verifying the original announcement before relying on the release or download status.

1. Установите Acti на телефон через страницу загрузки и включите клавиатуру в настройках ОС.
  — <https://openacti.com/dl/x>
2. В любом текстовом поле введите намерение, затем удерживайте Acti Bar, чтобы запустить действие.
  — <https://openacti.com/>
3. Для повторяемой задачи откройте Skill Builder, опишите действие простыми словами и назначьте созданный Skill на клавишу.
  — <https://openacti.com/acti-skill-hub/>
4. Перед подключением Gmail, Slack, Notion или другого сервиса проверьте, какой входной текст и какой инструмент использует конкретный Skill.
  — <https://openacti.com/privacy/>

## Best practices

- Начинайте с приватных Skills и публикуйте их только после проверки входов, подключённых инструментов и результата.
  — <https://openacti.com/acti-skill-hub/>
- Не передавайте чувствительный текст в Skill без необходимости: при запуске могут отправляться заданные входы, параметры и данные, нужные AI-провайдеру или подключённому инструменту.
  — <https://openacti.com/privacy/>
- Относитесь к результату Skill как к черновику: особенно проверяйте ссылки, переводы и действия во внешних сервисах перед отправкой.
  — <https://techcrunch.com/2026/06/30/acti-puts-ai-agents-directly-into-your-smartphone-keyboard/>
