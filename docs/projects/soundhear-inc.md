# Nova AI: nova-ai — Nova Ai

**Development line:** project:soundhear-inc · thread nova-ai

## What it is

Nova AI is a shell for AI music generation by SoundHear Inc. It runs as a standalone app and VST/VST3/AU/AAX plugin on Windows and macOS.

It brings local and cloud generation models into one window.

## Development line

- **2026-09-13 — Nova AI release by SoundHear Inc..** Nova AI music generation tool released, available as standalone app and VST/AU/AAX plugin, supporting local and cloud models.

## What changed

Nova AI was released on 2026-09-13. The app is free to use; models either run locally or carry separate cloud fees. It generates samples from a text prompt locally without an account, and extracts stems from existing audio to drag and drop into a DAW.

Cloud models are Suno, ElevenLabs, Stable Audio, ACE-Step, MiniMax, Mureka and YuE2. Local models are ACE-Step 1.5 Turbo, Stable Audio Small and YuE2 3B, plus a text model for lyrics.

## How to use this

1. Install Nova AI as a standalone app, or load it as a VST, VST3, AU or AAX plugin inside your DAW on Windows or macOS.
  — <https://www.novamusic.ai/>
2. Type a text prompt to generate samples with a local model; no account is needed.
  — <https://www.novamusic.ai/>
3. Load an existing audio file to extract stems, then drag and drop them straight into the DAW.
  — <https://www.novamusic.ai/>
4. To use a cloud model (Suno, ElevenLabs, Stable Audio, ACE-Step, MiniMax, Mureka or YuE2), pick it in the same window. These models are paid for separately.
  — <https://www.novamusic.ai/>

## Best practices

- Use the local models (ACE-Step 1.5 Turbo, Stable Audio Small, YuE2 3B) when you want to avoid model fees and accounts. Use the cloud models only when you need their output and accept the separate payment.
  — <https://www.novamusic.ai/>
