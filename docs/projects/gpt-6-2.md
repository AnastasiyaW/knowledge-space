## What it is

GPT-6.2 is an OpenAI model family for software engineering teams and automated development pipelines. It competes with Anthropic Claude and Google Gemini in agentic execution.

Abilities:

- Repository changes, end to end
- Automated code review
- Multi-step tool use
- Long-horizon task completion

Under standard limits, exploit generation is strictly filtered. Full autonomous penetration testing needs identity verification and tiered trusted-access approval. It automates work on production codebases and restricts offensive security use for unvetted accounts.

## What changed

The product line used to be single general-purpose checkpoints. It is now split in two: a high-reasoning tier and a lower-latency tier for daily engineering work. The heavy Astra variant takes long-horizon agentic planning and scientific evaluation. The Sol variant is tuned for high-volume automated code review and routine programming. Governance moved from uniform API filters to tiered compliance. Identity validation and explicit authorization are now mandatory for high-risk exploit synthesis, and telemetry is monitored centrally.
