## What it is

Runway Gen-1 was a video-to-video model for creators who needed to keep a source clip's structure while altering its appearance with a prompt or reference image.

- stylization
- storyboard
- masking
- render
- customization

Deprecated on 2025-04-06; use a modern Runway video model or Edit Studio instead. Historical context only, not a tool for new workflows today.

1. Open Runway in Chrome, sign in, and create a Session through Tools or an App.

2. For a new image-to-video shot, use the current model selector and upload a clean input image; use the prompt for subject, scene, and camera motion rather than re-describing the image.
  — <https://help.runwayml.com/hc/en-us/articles/48324313115155-Image-to-Video-Prompting-Guide>
3. Generate, inspect the result, then iterate the prompt or continue the output with the Use control.

## Best practices

- Start with one clear motion instruction and add elements one at a time; this makes failed motion easier to diagnose.
  — <https://help.runwayml.com/hc/en-us/articles/48324313115155-Image-to-Video-Prompting-Guide>
- Use a high-quality, artifact-free input image, because defects such as blurry hands or faces can be intensified in video.
  — <https://help.runwayml.com/hc/en-us/articles/48324313115155-Image-to-Video-Prompting-Guide>
- Use direct positive descriptions of what should happen, not negative constraints or conversational commands.
  — <https://help.runwayml.com/hc/en-us/articles/39789879462419-Gen-4-Video-Prompting-Guide>
