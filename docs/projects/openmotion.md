# Openmotion: openmotion-open-source-release — Openmotion Open Source Release

OpenMotion is an open-source video and animation studio for developers and motion designers, an alternative to Claude Motion and CapCut.

**Development line:** project:openmotion · thread openmotion-open-source-release  
**Last event:** 2026-11-21 · 1 dated since 2026-11-21 · **Researched:** 2026-11-22 · confidence: high

## What it is

OpenMotion is an agentic studio where code drives the video. It suits developers and motion designers who want a code-driven alternative to Claude Motion and CapCut.

- Reference videos and natural language prompts become editable HTML, CSS, JavaScript and GSAP code.
- MOTION.md instruction files hold production recipes and transition timing.
- The Model Context Protocol connects local coding agents.
- An embedded visual timeline editor covers editing.
- Multi-provider generation produces images, speech and background audio.

It needs external API keys for the commercial generation providers. It also needs compatible coding agent harnesses running locally. The workflow is video as code, so the motion logic stays out of closed-source generative platforms.

## Development line

- **2026-11-21 — OpenMotion officially released as open source.** The tool combines animation creation and video editing. The release includes:
  - over 300 video templates and 152 design systems
  - MOTION.md instruction files for AI agents
  - image, video, voice and music generation through connected models
  - compatibility with more than 20 AI agents and 74 service providers
  - MCP and plugin access, plus a built-in video editor
  - The repository does code-driven video synthesis with HTML, CSS and GSAP. It adds MOTION.md prompt specifications for local coding agents, including Claude Code and DeepSeek Harness. It also implements Model Context Protocol (MCP) integrations with BYOA and BYOK multimodal pipelines. (2026-11-21) — <https://github.com/nexu-io/openmotion>

## What changed

The codebase is now public. That covers the reference-driven motion engine, the MOTION.md specification and the embedded timeline studio, so others can integrate them.

## How to use this

1. Clone the OpenMotion repository. Configure the MCP server connection in a supported coding agent such as Claude Code or Codex.
  — <https://github.com/nexu-io/openmotion>
2. Give it a reference video URL or a prompt. It splits the layout, timing and transition rules into a MOTION.md file.
  — <https://github.com/nexu-io/openmotion>
3. Open the local visual timeline studio. Adjust styling, apply brand kits, add media through the configured provider keys, and export the composition to MP4.
  — <https://github.com/nexu-io/openmotion>

## Best practices

- Set animation timing, typography and easing in MOTION.md, so coding agents do not invent inconsistent motion styling.
  — <https://github.com/nexu-io/openmotion>
- Review agent-generated GSAP and HTML components in the timeline studio before rendering the final high-resolution MP4.
  — <https://github.com/nexu-io/openmotion>
