# Firefly Graph

## What it is

Firefly Graph is Adobe's visual canvas for building, running and sharing creative AI workflows from connected nodes.

- Model and tool integration: connect Adobe and partner models, Creative Cloud operations, input controls and export stages.
- Reusable templates: package repeatable processes into workflow templates.
- Stage inspection: preview intermediate outputs directly on nodes.

The official overview lists over 250 nodes; generative and external API nodes consume credits. It automates production workflows rather than replacing single prompt-to-image interfaces.

## How to use this

As of 2026-07-02, treat Firefly Graph as newly introduced and use the linked Adobe survey for feedback; do not assume technical workflow or availability changes from these links alone.

1. In Firefly Workspace, open New and create a Graph project.
  — <https://helpx.adobe.com/ca/firefly/web/get-started/access-the-app/firefly-workspace-overview.html>
2. Add a starting node: asset upload, Firefly generation, or object selection.
  — <https://helpx.adobe.com/firefly/web/firefly-graph/firefly-graph-overview.html>
3. Connect node outputs and inputs, then expose variable parameters as a slider, text field, angle dial, or color picker.
  — <https://helpx.adobe.com/firefly/web/firefly-graph/firefly-graph-overview.html>
4. Run the required nodes, inspect intermediate results, and adjust parameters: changing a step reruns downstream stages.
  — <https://helpx.adobe.com/firefly/web/firefly-graph/firefly-graph-overview.html>

## Best practices

- Start with a single measurable production process — such as variant generation, retouching, compositing, and export — rather than an all-purpose graph.
  — <https://helpx.adobe.com/firefly/web/firefly-graph/firefly-graph-overview.html>
- Package the stable part of a workflow into a capsule for reuse, exposing only necessary control parameters.
  — <https://helpx.adobe.com/firefly/web/firefly-graph/firefly-graph-overview.html>
- Check credit estimates before running; inspect which node or fan-out causes variable pricing on nodes marked Credits vary.
  — <https://helpx.adobe.com/creative-cloud/apps/generative-ai/generative-credits-faq.html?pubDate=20250502>
- Evaluate partner models individually for the project and verify regional availability.
  — <https://helpx.adobe.com/ca/creative-cloud/apps/generative-ai/non-adobe-models-in-adobe-products.html>
