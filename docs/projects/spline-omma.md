## What it is

Omma is Spline's tool for designers and developers building interactive web experiences without separate 3D, code, and media workflows.

- Parallel generation of code, images, and 3D
- Asset imports for CSV, JSON, DOC, GLB/GLTF, and media
- Community remixes and project publishing
- Custom domains for deployed projects

Free tier: 50 credits per month and 20 chat messages.

It works well for fast interactive prototypes and live web projects, but generation runs require planning around the credit budget.
