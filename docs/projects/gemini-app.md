# Gemini

Gemini is Google's model line and app; on Mac it now runs desktop tasks in a background window for US subscribers.

**Development line:** project:gemini-app · thread gemini-development  
**Last event:** 2026-11-20 · 7 dated since 2024-02-16 · **Researched:** 2026-11-21 · confidence: high

## What it is

Gemini app Computer Use for Mac does repetitive desktop work for subscribers. It runs across local macOS apps and web services, so there is no manual clicking and no automation tool that takes over the screen. Abilities:

- Multi-step interactions: clicks buttons, types text, navigates menus and fills forms in desktop apps and browser windows.
- Background window: runs in an isolated window, so the main display, mouse cursor and keyboard stay free for you.
- Live preview: shows progress inside the Gemini chat.
- Data extraction: pulls structured data from local documents into web forms and productivity software.
- Controls: application-level access control, blocked application lists, on-demand file backups and manual approval prompts before critical actions.

Limits: it needs an Apple Silicon Mac running macOS, Accessibility and Screen Recording permissions, a personal Google AI subscription tier and US English prompts. Enterprise and educational workspaces are excluded. It automates local apps without interrupting your work. Reliable runs depend on granting permissions carefully and watching complex actions.

## What changed

Desktop AI assistants used to need dedicated API environments, or total takeover of the input devices, to control a graphical interface. On macOS, GUI automation now runs in an isolated window decoupled from the hardware cursor, so the user can keep working during a task. Gemini went from conversation to direct system actions: native file management, data transfer between apps, and execution guarded by user approval.

## How to use this

1. Install and open the official Gemini app on an Apple Silicon Mac running macOS. Sign in with a personal Google account on an eligible Google AI tier.
  — <https://blog.google/innovation-and-ai/products/gemini-app/computer-use-mac/>
2. Open Gemini Settings from the menu bar (or press Command + Comma), select Computer use in the sidebar, and toggle on 'Allow Gemini to work with your Mac'.
  — <https://blog.google/innovation-and-ai/products/gemini-app/computer-use-mac/>
3. Grant the macOS permissions for Accessibility and Screen & System Audio Recording when System Settings asks.
  — <https://blog.google/innovation-and-ai/products/gemini-app/computer-use-mac/>
4. Add sensitive apps to the Blocked apps list in Gemini Settings. This step is optional.
  — <https://blog.google/innovation-and-ai/products/gemini-app/computer-use-mac/>
5. Start a task in the Gemini prompt bar with the @Computer use tag or plain instructions. Follow progress in the live preview panel and approve critical actions when asked.
  — <https://blog.google/innovation-and-ai/products/gemini-app/computer-use-mac/>

## Best practices

- Add password managers, personal banking apps and sensitive communication tools to the Blocked apps list first, so no data is exposed by accident.
  — <https://blog.google/innovation-and-ai/products/gemini-app/computer-use-mac/>
- Keep the live preview visible during the first runs of a complex workflow, so you can check accuracy and answer confirmation requests quickly.
  — <https://blog.google/innovation-and-ai/products/gemini-app/computer-use-mac/>
- Split multi-stage workflows into separate prompts with a verification point before any destructive step, such as bulk file deletion or batch document overwriting.
  — <https://blog.google/innovation-and-ai/products/gemini-app/computer-use-mac/>
- Turn on file backups before delegating document transformation or file renaming.
  — <https://blog.google/innovation-and-ai/products/gemini-app/computer-use-mac/>
