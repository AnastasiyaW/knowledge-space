# YouTube

## What it is

YouTube is a video platform for viewers and creators.

- Ask YouTube answers questions about the video.
- Automatic dubbing generates translated audio tracks.
- Studio lets creators manage dub tracks.

Availability depends on region, language, account, and the specific video.

These built-in tools help educational videos reach international audiences, but AI answers and dubbing require human review.

## How to use this

From 2024-12-11, we treat YouTube automatic dubbing as an evolving localization tool. After the 2026-02-05 expressive-speech update, retest dubbed audio quality before relying on it for publication.

1. For creators: turn on Automatic dubbing in YouTube Studio, and enable manual review to check tracks before release.
  — <https://support.google.com/youtube/answer/15569972?hl=en-EN>
2. For creators: open the video in Studio → Languages, listen to the dub, and publish, unpublish, or delete the track.
  — <https://support.google.com/youtube/answer/15569972?hl=en-EN>
3. For viewers: on supported videos, tap Ask below the video, then choose a prompt or ask a question about the content.
  — <https://support.google.com/youtube/answer/14110396?hl=en>
4. For viewers: switch between original and translated tracks on dubbed videos, or set preferred languages.
  — <https://support.google.com/youtube/answer/15569972?hl=en-EN>

## Best practices

- Set the source language correctly before uploading, so the automatic translation does not fail. We cannot edit an automatic dub directly, but YouTube can generate a new one after correcting the source language.
  — <https://support.google.com/youtube/answer/15569972?hl=en-EN>
- Turn on manual review and have a native speaker listen to dub tracks, especially for names, idioms, technical terms, background noise, and accents.
  — <https://support.google.com/youtube/answer/15569972?hl=en-EN>
- Do not use Ask YouTube for professional medical, legal, or financial advice. An LLM generates the answers, and accuracy varies.
  — <https://support.google.com/youtube/answer/14110396?hl=en>
