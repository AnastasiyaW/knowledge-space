# Odyssey

**Development line:** `project:odyssey` · thread `odyssey`  
**Last event:** 2025-06-02 · 2 dated since 2024-07-12 · **Researched:** 2026-09-04 · confidence: medium

## What it is

Odyssey — AI-лаборатория, которая делает причинные world models вместо обычных video generators; возможности: интерактивная генерация следующего состояния, общая многопользовательская симуляция, синхронные аудио и видео. Ограничение: Odyssey-2 Max доступна только партнёрам в private beta. Вердикт: это платформа для прикладного R&D, а не подтверждённый массовый self-serve видеогенератор.
