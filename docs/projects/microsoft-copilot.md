# Microsoft Copilot

## What it is

Microsoft Copilot is Microsoft's AI assistant, announced on September 21, 2023, across Windows 11, Edge, Bing, Microsoft 365, and mobile.

- Users: consumers on Windows, Edge, Bing, and mobile, plus Microsoft 365 business users through the enterprise variant.
- Key capability: chat that combines web context, work data, and current PC activity, opened from the taskbar or with Win+C; image generation with DALL·E 3 in Bing and Edge (as stated at launch).
- Limits: this research covers the 2023 launch statements and late-2023 mobile launch reporting; the 2026 feature set, models, pricing, and regional availability were not researched.

## How to use this

1. Use Copilot in Windows 11 from the taskbar or with Win+C; it can also appear through a right-click. — <https://blogs.microsoft.com/blog/2023/09/21/announcing-microsoft-copilot-your-everyday-ai-companion/>
2. Use Copilot on the web through Edge and Bing; Bing offers personalized answers from chat history, which users can turn off. — <https://blogs.microsoft.com/blog/2023/09/21/announcing-microsoft-copilot-your-everyday-ai-companion/>
3. Use Microsoft 365 Copilot for work data: the enterprise chat searches work data and the web. — <https://blogs.microsoft.com/blog/2023/09/21/announcing-microsoft-copilot-your-everyday-ai-companion/>
4. For mobile, install the Copilot app from the App Store or Google Play; this step is not verified against the current listings. — <https://play.google.com/store/apps/details?id=com.microsoft.copilot>

## Best practices

- Review and turn off Bing personalization from chat history if you do not want it; Microsoft states users can turn it off. — <https://blogs.microsoft.com/blog/2023/09/21/announcing-microsoft-copilot-your-everyday-ai-companion/>
- Choose the surface before rollout: consumer Copilot, Bing and Edge, and Microsoft 365 Copilot are separate products with separate data contexts. — <https://blogs.microsoft.com/blog/2023/09/21/announcing-microsoft-copilot-your-everyday-ai-companion/>
- Check regional availability and feature parity per platform before relying on a feature. — <https://blogs.microsoft.com/blog/2023/09/21/announcing-microsoft-copilot-your-everyday-ai-companion/>
