## What it is

Adobe Photoshop is Adobe's desktop image editor. This page tracks its product updates from dated Adobe announcements and their stated availability.

- Users: photographers, retouchers and designers working in the desktop application.
- Key capability in the 2026-08-27 announcement: an AI Assisted Editor (beta) for prompt-based edits, alongside Light Adjustment Layer, Instruct Edit with Masks and Dynamic Text for shapes and paths.
- Limits: the announcement states availability only for the AI Assisted Editor (beta). Instruct Edit with Masks is captioned as a Firefly Image 5 "(Preview)".

As of 2026-11, this page rests on one primary Adobe post. The official What's new page did not load for this research.

## What changed

- 2026-08-27 — Adobe announced Light Adjustment Layer, Instruct Edit with Masks (Firefly Image 5, Preview), Markup, Dynamic Text for shapes and paths, Stock panel integration, and the AI Assisted Editor in beta. Only the AI Assisted Editor carries a stated status (Beta).
  — <https://blog.adobe.com/en/publish/2026/08/27/new-photoshop-innovations-bring-you-more-choice-control-at-every-stage-of-your-creative-process>

## How to use this

1. Read the 2026-08-27 Adobe post for the feature list and their labels (Beta, Preview).
  — <https://blog.adobe.com/en/publish/2026/08/27/new-photoshop-innovations-bring-you-more-choice-control-at-every-stage-of-your-creative-process>
2. Before using any announced feature in client work, check its status in the installed version's What's new page. The post does not state availability for most features.
  — Adobe What's new page (not read during this research): <https://helpx.adobe.com/photoshop/using/whats-new.html>
3. Test the AI Assisted Editor (beta) on copies. The post describes Prompt to Edit creating a generative layer, so review those layers before export.
  — <https://blog.adobe.com/en/publish/2026/08/27/new-photoshop-innovations-bring-you-more-choice-control-at-every-stage-of-your-creative-process>
4. Use the Light Adjustment Layer for lighting changes; the post describes it as non-destructive.
  — <https://blog.adobe.com/en/publish/2026/08/27/new-photoshop-innovations-bring-you-more-choice-control-at-every-stage-of-your-creative-process>

## Best practices

- Keep an unedited source file. Generative edits change pixels, and the post describes generative layers created by Prompt to Edit.
  — <https://blog.adobe.com/en/publish/2026/08/27/new-photoshop-innovations-bring-you-more-choice-control-at-every-stage-of-your-creative-process>
- Do not treat a Preview feature as stable. The post labels Instruct Edit with Masks as Preview and gives no general availability date.
  — <https://blog.adobe.com/en/publish/2026/08/27/new-photoshop-innovations-bring-you-more-choice-control-at-every-stage-of-your-creative-process>
