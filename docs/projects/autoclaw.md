## What it is

AutoClaw is a desktop application for delegating research, documents, data analysis, automation, and engineering tasks to an agent.

- 50+ built-in skills to execute agent tasks
- Local files to inspect and edit documents on disk
- Browser actions to interact with web pages
- IM integrations to connect chat workflows
- GLM models to run inference

Model calls require an internet connection.
We get a managed desktop harness for agent tasks, not a standalone model.
