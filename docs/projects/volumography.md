## What it is

A directory for artists, coders and researchers working with Gaussian Splatting, photogrammetry, NeRF, LiDAR and related 3D/4D capture.

- Creator browsing: filter artists by medium and application tags.
- Portfolio review: inspect linked portfolios to evaluate work or find collaborators.
- Profile submission: add a creator profile through a form or GitHub pull request.

It documents no capture runtime, model, API, pricing or production workflow. Use it to discover practitioners or present a portfolio; choose a separate capture or 3DGS tool for production.

## How to use this

1. Filter creators in the gallery by technique or application, including 3DGS, photogrammetry, NeRF, LiDAR, 4DGS, VFX and XR.
  — <https://volumography.com/>
2. Inspect work through individual creator links; the directory provides references, not capture or rendering software.
  — <https://github.com/nixliuxin/Awesome-Gaussian-Splatting-Artists>
3. To get listed, submit the form or fork the repository, add an asset folder with a creators.json entry, and open a pull request.
  — <https://github.com/nixliuxin/Awesome-Gaussian-Splatting-Artists/blob/main/CONTRIBUTING.md>

## Best practices

- Use the submission form for a standard listing. Use a pull request on GitHub when you need full control over profile assets and metadata.
  — <https://github.com/nixliuxin/Awesome-Gaussian-Splatting-Artists/blob/main/CONTRIBUTING.md>
- For a pull request, use a lowercase hyphenated creator ID, a square roughly 400x400 avatar, a 3:2 roughly 1200x800 cover, and gallery images under 500 KB in a supported raster format.
  — <https://github.com/nixliuxin/Awesome-Gaussian-Splatting-Artists/blob/main/CONTRIBUTING.md>
- Do not list image paths in creators.json. The workflow generates the assets manifest automatically when you submit the pull request.
  — <https://github.com/nixliuxin/Awesome-Gaussian-Splatting-Artists/blob/main/CONTRIBUTING.md>
