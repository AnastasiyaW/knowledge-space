## What it is

Lovart is a web workspace for generating brand images, video, and graphics through an agent or direct model selection.

- Canvas: arranges and edits assets on an open workspace.
- Brand Kit: manages logos, colors, fonts, and guidelines, or parses brand-book PDFs.
- Point editing: adjusts specific elements directly.
- Image and video generation: generates media via an agent or direct model selection.
- SVG vectorization: converts PNG and JPG raster images into SVG.
- PSD export: exports canvas contents to layered PSD files.

Canvas generates SVG files but cannot edit vector paths; path editing requires Illustrator, Figma, or another vector editor.
It serves as a working layer over multiple generative models rather than a replacement for a vector path editor.

## How to use this

1. Create a new project or start Quickstart; describe the task in plain text and check the result on Canvas.
  — <https://www.lovart.ai/docs/getting-started/design-your-first-project>
2. Set up Brand Kit first for an existing brand: upload logos, colors, fonts, and guidelines, or let the service parse a brand-book PDF; apply the kit to the project.
  — <https://www.lovart.ai/docs/getting-started/things-you-should-set-up-first>
3. Open Models for guided generation: Auto selects a model, Auto Off sets preferences, and an @-mention fixes a specific model for a single prompt.
  — <https://www.lovart.ai/docs/how-to-prompt/selecting-ai-models>
4. For SVG, select a PNG or JPG on Canvas, choose Vectorize, download the SVG, and open it in an external vector editor if needed.
  — <https://www.lovart.ai/docs/edit-your-design/ai-transformation>
5. Export a single object or select multiple objects; batch export supports PSD.
  — <https://www.lovart.ai/docs/getting-started/design-your-first-project>

## Best practices

- Build the Brand Kit before first generations for an existing brand, and maintain a separate kit for each brand.
  — <https://www.lovart.ai/docs/getting-started/things-you-should-set-up-first>
- Treat model preferences in auto-selection as preferences rather than strict locks; fix a specific model with @ when needed.
  — <https://www.lovart.ai/docs/how-to-prompt/selecting-ai-models>
- Remove backgrounds before Vectorize so logos and icons trace cleanly.
  — <https://www.lovart.ai/docs/edit-your-design/ai-transformation>
- Outline objects tightly for Move Object edits: wide selections hurt recognition in complex scenes.
  — <https://www.lovart.ai/docs/edit-your-design/ai-transformation>
