## What it is

Katalist is an AI creative studio for performance teams, not a standalone video model.

- Script conversion: turns a written or imported script into shots, storyboard frames, and short video clips.
- Production assets: provides character and location assets, scene controls, product swaps, voice, lip-sync, and timeline export.

## How to use this

From 2024-01-18, practitioners should check Katalist's early-access route before assuming general availability. Treat features, eligibility, and release status as unverified until separately evidenced.

1. Open Katalist and start a free account or canvas. Begin from a written brief, an imported script, or the script assistant.
  — <https://www.katalist.ai/>
2. In New Project, start from the script. Let Katalist split it into scenes and shots, then add the required scene to Story Canvas.
  — <https://help.katalist.ai/en/articles/16298583-how-to-build-your-storyboard-and-videos-in-story-canvas>
3. Generate character and location assets before the shots. Edit their image prompt, aspect ratio, resolution, model, and frame type, then generate storyboard frames.
  — <https://help.katalist.ai/en/articles/16298583-how-to-build-your-storyboard-and-videos-in-story-canvas>
4. For an approved frame, choose Add to New Video. Set the video prompt and settings, generate clips, arrange them on the timeline, and export the sequence.
  — <https://help.katalist.ai/en/articles/16298583-how-to-build-your-storyboard-and-videos-in-story-canvas>
5. For a creative variant, upload a real product reference. Request the product swap in the target shot or video, and review the resulting shot before export.
  — <https://www.katalist.ai/>

## Best practices

- Edit the generated script and control the number of scenes before creating the project, so unwanted scenes do not consume later work.
  — <https://help.katalist.ai/en/articles/10643422-how-to-make-complete-ai-videos-with-katalist-full-tutorial>
- Generate and tune characters and locations before their shots, so the chosen asset propagates to every referencing frame.
  — <https://help.katalist.ai/en/articles/16298583-how-to-build-your-storyboard-and-videos-in-story-canvas>
- Review and refine every storyboard frame before moving to the timeline. Change framing, characters, locations, or dialogue while it is still a frame.
  — <https://help.katalist.ai/en/articles/10643422-how-to-make-complete-ai-videos-with-katalist-full-tutorial>
- For lip-sync, keep dialogue to 300 characters and use one speaker per scene. If sync is wrong, adjust the dialogue and regenerate.
  — <https://help.katalist.ai/en/articles/12781817-how-to-add-a-lip-sync-in-katalist>
