## How to use this

1. Open 'Using GPT-6.2' under Get started in the OpenAI API docs, then follow its prompting rules for the latest model.
  — <https://developers.openai.com/api/docs/guides/latest-model>
2. State goals and success criteria as testable conditions like format, constraints, examples, and tests instead of vague requests like 'do it well'.
  — <https://developers.openai.com/api/docs/guides/latest-model>
3. Set autonomy limits by stating what the model may do alone and where it must ask first. Add a 'bias towards action' instruction to the system prompt for more initiative, because the model defaults to asking clarifying questions.
  — <https://developers.openai.com/api/docs/guides/latest-model>
4. Describe the workflow and verification stages explicitly for agentic setups.
  — <https://developers.openai.com/api/docs/guides/latest-model>

## Best practices

- Put static instructions at the start of prompts and dynamic data at the end so prompt caching works better.
  — <https://developers.openai.com/api/docs/guides/latest-model>
- Set reasoning.effort deliberately: low for simple tasks, high for complex work like architecture.
  — <https://developers.openai.com/api/docs/guides/latest-model>
- Cut stock phrases and clichés from prompts and outputs, such as 'delve into', 'leverage', and 'it's worth noting'.
  — <https://developers.openai.com/api/docs/guides/latest-model>
