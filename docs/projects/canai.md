## What it is

CanAI is an open-source desktop AI studio built around a node canvas. It is for creators who run multi-step image and video generation pipelines locally. It is a lightweight local alternative to hosted generative canvas apps.

- Infinite canvas: lays out references in space.
- Prompt assistance: helps with text and image prompts.
- Macro nodes: group several nodes into one block.
- Cloud dispatch: sends jobs straight to cloud generative models.

Generation needs your own fal.ai API key, so latency and cost depend on fal.ai's cloud, not on CanAI. The node graph itself stays visible and self-hosted.

## What changed

CanAI moved from private development to a public repository, with packaged Windows binaries and a live browser demo. Work focused on visual macro nodes and spatial layout on the infinite canvas. Model execution moved to an external API key setup.

## How to use this

1. Try canvas interaction and node grouping in the web demo before installing anything.
  — <https://canai-demo.synthid-rich-report-worker.workers.dev/>
2. Download the packaged Windows release, or clone the repository and run the studio locally.
  — <https://github.com/jimmorisedu-boop/CanAI-public>
3. Add your own fal.ai API key in settings so canvas nodes can generate images and video.
  — <https://github.com/jimmorisedu-boop/CanAI-public>
4. Lay out reference images, connect macro nodes and run generations on the infinite canvas.
  — <https://github.com/jimmorisedu-boop/CanAI-public>

## Best practices

- Bundle repeated prompt assistance and reference transformations into macro nodes so they become reusable blocks.
  — <https://github.com/jimmorisedu-boop/CanAI-public>
- Check node connections in the browser demo before starting billed runs on fal.ai.
  — <https://canai-demo.synthid-rich-report-worker.workers.dev/>
- Watch fal.ai usage limits and API token balance directly when running high-resolution image and video batches.
  — <https://github.com/jimmorisedu-boop/CanAI-public>
