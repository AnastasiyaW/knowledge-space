# Practical ML Conf

**Development line:** project:practical-ml-conf · thread practical-ml-conf

## What it is

Practical ML Conf is a Yandex conference for ML engineers, researchers and infrastructure practitioners. It is about running models in production, not academic theory.

Core topics:

- LLM pre-training and inference optimization
- agentic vision systems
- generative recommendation pipelines
- reinforcement learning for mixture-of-experts architectures
- ML infrastructure

The content is technical sessions only, split into specialized tracks. The main language is Russian, with selective international access. Enterprise ML teams get implementation architectures and production engineering references out of it.

## What changed

The conference grew from an internal and domestic engineering gathering into a multi-track event. It now has separate data, code, server infrastructure and network architecture sessions. The program moved from baseline computer vision and classic tabular models toward LLM pre-training, agentic reasoning, generative recommendation systems and the annual Yandex ML Prize.
