## What it is

Suno Studio 2.0 is a browser DAW for musicians who finish generations without switching programs.

- MIDI editing, audio recording, and audio import to assemble tracks.
- Wavetable synthesizer to generate instrument sounds.
- Audio effects and automation to shape track parameters.
- Chat Bar to generate sounds and custom effects.

Available only to Premier subscribers, with no VST or Audio Units support.
We get a Suno workspace to generate and finish tracks, not a DAW to replace third-party plugin setups.

## How to use this

As of 2026-08-13, we treat Suno Studio as a line that moved from a waitlist to Studio 2; verify access and features in Suno docs before relying on it.

1. Subscribe to Premier and open Studio in Google Chrome; Safari does not support Web MIDI.
  — <https://help.suno.com/en/articles/13670529>
2. Create or open a project, then import or record audio and MIDI on the timeline.
  — <https://suno.com/blog/studio-2>
3. Add a MIDI clip, edit notes, or use the clip to drive a new audio generation.
  — <https://suno.com/blog/studio-2>
4. Select a track, add an effect, and arrange the chain; device order changes the sound.
  — <https://help.suno.com/en/articles/13670785>
5. Open Chat Bar to build a custom effect, describe it, confirm settings, and save it to the library.
  — <https://help.suno.com/en/articles/13670785>
6. Export the finished track, stems, or multitrack; Premier Studio claims unlimited 32-bit/48 kHz export.
  — <https://suno.com/blog/studio-2>

## Best practices

- Use Chrome when connecting a MIDI controller: Safari lacks Web MIDI support.
  — <https://help.suno.com/en/articles/13670529>
- Check new generations with a metronome and soloed track: Suno notes generations can drift off beat.
  — <https://help.suno.com/en/articles/13670529>
- Build effect chains deliberately and test with bypass: reordering devices changes the sound.
  — <https://help.suno.com/en/articles/13670785>
- Use keyboard shortcuts for transport, recording, saving, and undo to avoid switching panels.
  — <https://help.suno.com/en/articles/13680385>
