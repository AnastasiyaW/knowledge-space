# Krea

## What it is

Krea Agents is Krea’s application-based workspace for creative practitioners. It combines project files, persistent context, reusable image-based skills, Pinterest moodboards, connected work tools and media publishing. Access is reported to be application-based, but the supported model and tool inventories were not publicly listed. The evidence supports a cloud product for creative workflows, not a general replacement for external APIs or every production tool.

## What changed

2026-09-03 — Krea Agents was presented as a planned platform for specialized agents in visual design, marketing and advertising. It was intended to connect to MCP and APIs, but public access details were not available. The later release is represented by the reviewed event entries. Public reporting describes application-based access, project-file context, Pinterest import, custom skills and integrations.

## How to use this

1. Request access through the Agents beta flow; reporting describes access as application-based.
  — <https://modelora.ru/news/krea-vypustila-ii-agentov-agents-dlya-2026-09-11>
2. Upload project files and references. Describe the intended result, then choose the available language-model and effort settings.
  — <https://modelora.ru/news/krea-vypustila-ii-agentov-agents-dlya-2026-09-11>
3. Import a Pinterest moodboard or another visual reference. Create an image-set skill when prompts need to invoke a recurring style.
  — <https://modelora.ru/news/krea-vypustila-ii-agentov-agents-dlya-2026-09-11>
4. Connect Slack, Figma or Google Drive when their project material is needed in the agent context. Review generated media before using the reported social-publishing capability.
  — <https://modelora.ru/news/krea-vypustila-ii-agentov-agents-dlya-2026-09-11>

## Best practices
