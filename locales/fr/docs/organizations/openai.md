## Présentation {#what-it-is}

OpenAI est le fournisseur de ChatGPT, de ChatGPT Work, de Codex et de l'API pour les particuliers, les équipes et les développeurs. Par sa portée, elle rivalise avec les offres combinées d'Anthropic (Claude et API) et de Google (Gemini et Vertex AI), et non avec un simple chatbot.

- ChatGPT : dialogues, recherche, analyse de fichiers, images et voix ;
- Work : tâches de longue durée avec applications, fichiers, navigateur et documents finalisés ;
- Codex : travail sur les dépôts, le terminal, les tests et les revues de code ;
- API : Responses, outils, utilisation de l'ordinateur, recherche, multimodalité et processus agentiques.

## Comment l'utiliser {#how-to-use-this}

Au 2026-06-26, les praticiens doivent choisir les modèles et fonctions de plateforme d'OpenAI selon la version exacte documentée et la capacité d'API précise, et revalider l'accès, la tarification, l'état des tests de sécurité et la compatibilité avant tout déploiement, plutôt que de présumer que le comportement se transmet d'une génération à l'autre.

1. OpenAI ChatGPT : connectez-vous via le web ou l'application de bureau et choisissez Chat pour un dialogue court, Work pour un résultat de longue durée, ou Codex pour le code.
  — <https://learn.chatgpt.com/docs/quickstart>
2. OpenAI Work : créez une tâche, joignez les documents sources, précisez le résultat attendu et les contraintes, puis suivez les actions, répondez aux questions et validez les opérations importantes.
  — <https://learn.chatgpt.com/docs/get-started-with-work>
3. OpenAI Codex : installez la CLI, connectez-vous à votre compte, lancez-la depuis la racine du dépôt Git et enregistrez des points de contrôle avant les modifications agentiques.
  — <https://learn.chatgpt.com/docs/codex/cli>
4. OpenAI API : créez une clé, stockez-la dans une variable d'environnement, installez le SDK officiel et envoyez une première requête via la Responses API.
  — <https://developers.openai.com/api/docs/quickstart>
5. OpenAI API : choisissez Astra pour le travail de bout en bout le plus complexe, Terra pour l'équilibre entre qualité et prix, Luna pour un flux de masse économique ; vérifiez d'abord l'accès de votre offre et de votre région.
  — <https://developers.openai.com/api/docs/models>
6. OpenAI Responses : migrez les processus agentiques nouveaux et anciens vers Responses, en activant la recherche web, la recherche de fichiers, l'utilisation de l'ordinateur ou des fonctions personnalisées uniquement si nécessaire.
  — <https://developers.openai.com/api/docs/guides/migrate-to-responses>
7. OpenAI Evals : constituez un ensemble représentatif d'exemples, définissez des critères vérifiables et comparez les modèles, prompts et réglages avant de mettre à jour le flux en production.
  — <https://developers.openai.com/api/docs/guides/evals>
8. Agents OpenAI : conservez le répertoire de travail comme limite par défaut, configurez le réseau et les confirmations, et n'accordez un accès complet qu'à une tâche explicitement approuvée.
  — <https://learn.chatgpt.com/docs/permission-modes>

## Bonnes pratiques {#best-practices}

- OpenAI Astra : définissez explicitement le résultat, l'ordre de priorité des instructions, le degré d'autonomie admis et le critère de validation ; vérifiez les skills et AGENTS.md, car le modèle est plus sensible aux consignes qu'ils contiennent.
  — <https://developers.openai.com/api/docs/guides/latest-model?model=gpt-6-astra>
- API OpenAI : choisissez le modèle et l'effort de raisonnement à partir de vos propres evals, et non de la classe la plus élevée ; Astra ne prend pas en charge effort=none, et l'appel d'outils sur ce modèle exige la Responses API.
  — <https://developers.openai.com/api/docs/guides/latest-model?model=gpt-6-astra>
- OpenAI Prompt Caching : placez les instructions et exemples invariables au début de la requête, les données dynamiques à la fin, et mesurez les cache hits, le coût et la latence.
  — <https://developers.openai.com/api/docs/guides/prompt-caching>
- Agents OpenAI : combinez bac à sable et confirmations ; validez séparément les envois externes, les achats, les suppressions et les extensions d'accès, et n'utilisez pas le accès complet comme mode ordinaire.
  — <https://learn.chatgpt.com/docs/agent-approvals-security>
- Connecteurs OpenAI : ne connectez que les dépôts et sources nécessaires ; utilisez GitHub dans ChatGPT pour la lecture et la recherche, et effectuez les écritures et les push via Codex avec des autorisations distinctes.
  — <https://help.openai.com/en/articles/11145903-connecting-github-to-chatgpt-deep-research>
- OpenAI Deep Research : définissez les sources autorisées, vérifiez le plan proposé, ajustez la recherche en cours de route et ouvrez les sources primaires derrière les citations avant d'utiliser le résultat.
  — <https://help.openai.com/en/articles/10500283-deep-research>
- OpenAI Work : transmettez les documents réels, le contexte, les contraintes, le format du résultat et les règles de revue au lieu d'une demande générale ; vérifiez l'artefact final et ses preuves.
  — <https://learn.chatgpt.com/docs/get-started-with-work>
- OpenAI Astra : ne considérez pas le raisonnement interne comme un audit suffisant ; conservez les limites de pouvoir, les vérifications externes et les journaux d'actions, car l'évaluation officielle a relevé une dégradation de la monitorability dans des conditions adverses.
  — <https://openai.com/index/safety-overview-gpt-6-astra/>

## Éléments remplacés {#superseded-by-this}

- 2022-04-07 et 2026-08-30 — le DALL·E 2 autonome et le GPT officiel DALL·E ne constituent plus la voie actuelle ; c'est ChatGPT Images qui est utilisé.
- 2022-12-01 — la description de ChatGPT comme aperçu de recherche gratuit reposant sur GPT‑3.5 ne reflète plus les offres actuelles Chat, Work, Codex, les tarifs et les familles de modèles.
- 2023-03-14 — la liste d'attente de GPT‑4, les contextes 8K/32K et les tarifs initiaux ne conviennent plus au choix d'un modèle aujourd'hui ; c'est le catalogue API actuel qui fait référence.
- 2023-03-23 — le protocole initial des plugins ChatGPT et l'alpha limitée sont obsolètes ; depuis le 2026-07-09, le catalogue principal est le Plugin Directory, avec des paquets de skills, d'applications et de modèles.
- 2023-08-23 — l'endpoint /v1/fine-tunes a été désactivé le 2024-01-04 ; GPT‑3.5 Turbo ne doit plus servir de référence actuelle pour le fine-tuning.
- 2024-01-11 — ChatGPT Team a été renommé ChatGPT Business le 2025-08-29 ; l'ancien nom de l'offre est obsolète.
- 2024-08-13 — les résultats obtenus sur le SWE‑bench d'origine ou sur Lite ne peuvent pas être présentés directement comme des résultats sur SWE‑bench Verified ; une comparaison requiert l'ensemble vérifié et une version documentée du harnais.
- 2024-10-02 — la Realtime API n'est plus en bêta : la version généralement disponible est sortie le 2025-08-28.
- 2024-10-02 — la formulation initiale du Prompt Caching avec une remise de 50 % ne reflète plus les tarifs actuels de lecture et d'écriture du cache, les TTL et les tarifs d'Astra.
- 2024-10-02 — le fine-tuning de la vision n'accepte plus de nouveaux utilisateurs depuis le 2026-05-08 et est abandonné avec les modèles de base.
- 2024-12-21 — les candidatures au programme Early Access for Safety Testing ont pris fin le 2025-01-10 ; ce n'est plus une forme d'accès en vigueur.
- 2025-03-11 — l'Assistants API a été supprimée le 2026-08-26 ; les nouvelles applications et migrations utilisent la Responses API.
- 2025-06-19 — l'ancien canal WhatsApp mondial a pris fin le 2026-01-15 ; depuis le 2026-07-13, l'accès n'est rétabli que pour les numéros de l'EEE et se déploie progressivement.
- 2025-07-17 — la première version autonome de ChatGPT agent est marquée obsolète ; la voie actuelle pour les tâches de longue durée est ChatGPT Work et Workspace Agents.
- 2026-06-26 — les conditions du préaccès limité de GPT‑5.6 Sol ont été supplantées par la sortie générale du 2026-07-09 ; GPT‑6 Astra, depuis le 2026-09-03, est la variante plus récente pour les travaux complexes, mais ne remplace pas Terra et Luna pour le prix et la vitesse.
- 2026-09-04 — l'API Evals est encore disponible, mais la plateforme Evals elle-même passe en lecture seule le 2026-10-31 et fermera le 2026-11-30 ; les nouveaux ensembles d'évaluation doivent être construits selon la voie actuelle des Datasets.
