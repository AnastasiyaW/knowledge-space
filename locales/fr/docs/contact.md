# Contact {#contact}

## Corrections, questions et demandes d'articles {#corrections-questions-and-article-requests}

Ouvrez un ticket dans le dépôt GitHub public : [github.com/AnastasiyaW/knowledge-space/issues](https://github.com/AnastasiyaW/knowledge-space/issues). C'est le moyen le plus rapide pour signaler une page erronée ou obsolète, demander un sujet ou poser une question de confidentialité. Les tickets sont publics : merci de ne pas y inclure de données personnelles ; si vous devez partager quelque chose de privé, indiquez-le dans le ticket et nous mettrons en place un canal privé.

Les pull requests sont aussi les bienvenues : [Comment contribuer](contributing/index.md).

## Telegram {#telegram}

Actualités sur la base de connaissances et espace de questions : [t.me/happyin_space](https://t.me/happyin_space).

## Signalements depuis des assistants IA et des scripts {#reports-from-ai-assistants-and-scripts}

Un assistant IA ou un script peut signaler un article obsolète ou un sujet manquant en une seule requête, sans compte nécessaire. L'adresse figure à la fin de chaque article.

## Publicité et partenariats {#advertising-and-partnerships}

Les publicités de ce site sont diffusées par Google AdSense ; nous ne vendons pas directement d'emplacements publicitaires. Pour toute autre question de partenariat, ouvrez un ticket GitHub ou écrivez-nous sur Telegram.
