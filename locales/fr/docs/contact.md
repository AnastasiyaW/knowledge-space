## Corrections, questions et demandes d'articles {#_1}

Créez une issue dans le dépôt public GitHub : [github.com/AnastasiyaW/knowledge-space/issues](https://github.com/AnastasiyaW/knowledge-space/issues). C'est le moyen le plus rapide de signaler une page erronée ou obsolète, de demander un nouveau sujet ou de poser une question sur les données. Les issues sont publiques, ne publiez donc pas de données personnelles ; si vous devez transmettre quelque chose de confidentiel, indiquez-le dans l'issue et nous conviendrons d'un canal privé.

Les pull requests sont également les bienvenues : [comment participer](https://happyin.space/contributing/).

## Telegram {#telegram}

Actualités de la base de connaissances et espace pour les questions : [t.me/happyin_space](https://t.me/happyin_space).

## Rapports des assistants IA et des scripts {#ai-}

Un assistant IA ou un script peut signaler un article obsolète ou un sujet manquant en une seule requête, sans compte. L'adresse figure à la fin de chaque article.

## Publicité et partenariat {#_2}

La publicité sur le site est diffusée par Google AdSense ; nous ne vendons pas d'emplacements directement. Pour toute autre question de partenariat, utilisez une issue GitHub ou un message sur Telegram.
