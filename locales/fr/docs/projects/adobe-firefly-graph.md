# Firefly Graph {#firefly-graph}

## Ce que c'est {#what-it-is}

Firefly Graph est le canevas visuel d'Adobe pour concevoir, exécuter et partager des workflows d'IA créative à partir de nœuds connectés.

- Intégration de modèles et d'outils : connecter les modèles d'Adobe et de partenaires, les opérations Creative Cloud, les contrôles d'entrée et les étapes d'export.
- Modèles réutilisables : regrouper des processus répétables dans des modèles de workflow.
- Inspection des étapes : prévisualiser les sorties intermédiaires directement sur les nœuds.

La présentation officielle recense plus de 250 nœuds ; les nœuds génératifs et les nœuds d'API externes consomment des crédits. Il automatise les workflows de production plutôt que de remplacer les interfaces monoprompt vers image.

## Ce qui a changé {#what-changed}

- 2025-10 — Adobe a présenté Project Graph à Adobe MAX comme prédécesseur du produit.
- 2026-06-17 — Adobe a lancé Firefly Graph pour Creative Cloud for Enterprise Edition 5 ; la présentation officielle décrivait plus de 250 nœuds et des graphes pas à pas.
- 2026-07-02 — Adobe désignait toujours la version destinée aux utilisateurs individuels comme une future bêta privée ; les clients entreprise demandaient l'accès via un représentant Adobe.
- 2026-08-11 — La documentation de Firefly Workspace a ajouté Graph au menu de création de projet, y compris les modèles de workflow.
- 2026-09-03 — L'aide d'Adobe a listé Firefly Graph parmi les surfaces pour les modèles partenaires ; la disponibilité des modèles dépend du pays ou de la région.

## Comment l'utiliser {#how-to-use-this}

Au 2026-07-02, considérez Firefly Graph comme nouvellement introduit et utilisez l'enquête Adobe liée pour les retours ; ne supposez pas de changements techniques de workflow ou de disponibilité à partir de ces seuls liens.

1. Dans Firefly Workspace, ouvrez Nouveau et créez un projet Graph.
  — <https://helpx.adobe.com/ca/firefly/web/get-started/access-the-app/firefly-workspace-overview.html>
2. Ajoutez un nœud de départ : import d'un asset, génération Firefly ou sélection d'objet.
  — <https://helpx.adobe.com/firefly/web/firefly-graph/firefly-graph-overview.html>
3. Connectez les sorties et entrées des nœuds, puis exposez les paramètres variables sous forme de curseur, de champ de texte, de cadran d'angle ou de sélecteur de couleur.
  — <https://helpx.adobe.com/firefly/web/firefly-graph/firefly-graph-overview.html>
4. Exécutez les nœuds requis, inspectez les résultats intermédiaires et ajustez les paramètres : modifier une étape relance les étapes en aval.
  — <https://helpx.adobe.com/firefly/web/firefly-graph/firefly-graph-overview.html>

## Bonnes pratiques {#best-practices}

- Commencez par un processus de production unique et mesurable — tel que la génération de variantes, la retouche, la composition et l'export — plutôt que par un graphe polyvalent.
  — <https://helpx.adobe.com/firefly/web/firefly-graph/firefly-graph-overview.html>
- Regroupez la partie stable d'un workflow dans une capsule réutilisable, en n'exposant que les paramètres de contrôle nécessaires.
  — <https://helpx.adobe.com/firefly/web/firefly-graph/firefly-graph-overview.html>
- Vérifiez les estimations de crédits avant l'exécution ; repérez quel nœud ou quelle ramification entraîne une tarification variable sur les nœuds marqués Credits vary.
  — <https://helpx.adobe.com/creative-cloud/apps/generative-ai/generative-credits-faq.html?pubDate=20250502>
- Évaluez les modèles partenaires individuellement pour le projet et vérifiez leur disponibilité régionale.
  — <https://helpx.adobe.com/ca/creative-cloud/apps/generative-ai/non-adobe-models-in-adobe-products.html>
