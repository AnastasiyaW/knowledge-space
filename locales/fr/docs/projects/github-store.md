## Description {#what-it-is}

Komi Store (anciennement GitHub Store) est un navigateur et installateur de versions pour Kotlin Multiplatform.

- Découverte de ressources : recense les projets disposant de ressources installables.
- Téléchargement de paquets : récupère les paquets APK, EXE, DMG, AppImage et DEB adaptés à la plateforme.
- Suivi des mises à jour : surveille les versions et bloque les APK si la clé de signature Android change.

## Historique des changements {#what-changed}

- 2026-03-31 — GitHub Store était accessible via son site web d'origine et le dépôt OpenHub-Store. Les liens conservés ne permettent pas d'établir sa version exacte ni l'étendue de ses versions à cette date.
- 2026-06-11 — La version 1.9.1 a renommé GitHub Store en Komi Store afin d'éviter un risque de marque lié à GitHub. La version a transféré le projet vers Kurikomi et conservé les bibliothèques, paramètres, jetons et enregistrements des applications installées des utilisateurs.
- 2026-07-03 — L'organisation OpenHub-Store précédente a été archivée et marquée comme non maintenue. La page d'accueil active du projet est Komi Store.

## Mode d'emploi {#how-to-use-this}

Évaluez GitHub Store à partir de son site web et de son dépôt liés avant de le considérer comme une version, une fonctionnalité ou un flux de travail vérifié et maintenu à la date du 2026-03-31.

1. Ouvrez la page de téléchargement et choisissez le paquet pour votre plateforme : Android 8+, Windows 10/11 x64, macOS 12+ ou Linux x86_64.
  — <https://komistore.app/download/>
2. Parcourez le flux, consultez le README, le journal des modifications et les ressources de version, puis choisissez le binaire pour votre appareil.
  — <https://komistore.app/>
3. Installez le paquet et suivez les mises à jour. Sur Android, activez les installations silencieuses uniquement si l'autorité de l'appareil l'autorise.
  — <https://komistore.app/download/>

## Bonnes pratiques {#best-practices}

- Considérez le store comme un outil de découverte de versions plutôt que comme une revue de sécurité. Vérifiez l'éditeur et la ressource avant d'exécuter un binaire.
  — <https://github.com/komi-store/komi-store>
- Vérifiez l'empreinte du certificat Android et comparez les empreintes des installateurs de bureau aux ressources de version publiées.
  — <https://komistore.app/download/>
- Choisissez la version F-Droid sur Android lorsque vous avez besoin de builds reproductibles et vérifiés.
  — <https://komistore.app/download/>
