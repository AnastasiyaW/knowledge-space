## Description {#what-it-is}

Un répertoire destiné aux artistes, développeurs et chercheurs travaillant avec le Gaussian Splatting, la photogrammétrie, le NeRF, le LiDAR et les captures 3D/4D associées.

- Parcours des créateurs : filtrage des artistes par médium et par étiquettes d'application.
- Revue de portfolio : consultation des portfolios liés pour évaluer un travail ou trouver des collaborateurs.
- Soumission de profil : ajout d'un profil de créateur via un formulaire ou une pull request GitHub.

Il ne documente ni environnement d'exécution de capture, ni modèle, ni API, ni tarification, ni workflow de production. Utilisez-le pour découvrir des praticiens ou présenter un portfolio ; pour la production, choisissez un outil de capture ou de 3DGS distinct.

## Mode d'emploi {#how-to-use-this}

1. Filtrez les créateurs de la galerie par technique ou par application, notamment 3DGS, photogrammétrie, NeRF, LiDAR, 4DGS, VFX et XR.
  — <https://volumography.com/>
2. Consultez les travaux via les liens individuels des créateurs ; le répertoire fournit des références, et non des logiciels de capture ou de rendu.
  — <https://github.com/nixliuxin/Awesome-Gaussian-Splatting-Artists>
3. Pour être référencé, soumettez le formulaire ou forkez le dépôt, ajoutez un dossier d'assets avec une entrée creators.json, puis ouvrez une pull request.
  — <https://github.com/nixliuxin/Awesome-Gaussian-Splatting-Artists/blob/main/CONTRIBUTING.md>

## Bonnes pratiques {#best-practices}

- Utilisez le formulaire de soumission pour une inscription standard. Utilisez une pull request sur GitHub lorsque vous avez besoin d'un contrôle total sur les assets et les métadonnées du profil.
  — <https://github.com/nixliuxin/Awesome-Gaussian-Splatting-Artists/blob/main/CONTRIBUTING.md>
- Pour une pull request, utilisez un identifiant de créateur en minuscules avec tirets, un avatar carré d'environ 400x400, une couverture 3:2 d'environ 1200x800, et des images de galerie de moins de 500 Ko dans un format raster pris en charge.
  — <https://github.com/nixliuxin/Awesome-Gaussian-Splatting-Artists/blob/main/CONTRIBUTING.md>
- Ne listez pas les chemins d'images dans creators.json. Le workflow génère automatiquement le manifeste des assets lorsque vous soumettez la pull request.
  — <https://github.com/nixliuxin/Awesome-Gaussian-Splatting-Artists/blob/main/CONTRIBUTING.md>
