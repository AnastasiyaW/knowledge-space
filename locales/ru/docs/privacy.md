# Приватность

Русская ветка не добавляет отдельную систему сбора данных. Она использует те же публичные страницы и те же правила, что и английская база.

## Аналитика

Google Analytics 4 не загружается, пока владелец не настроил измерение **и** посетитель явно не выбрал «Разрешить аналитику». При согласии измеряются только агрегированные действия: просмотр страницы, поиск без текста запроса, открытие результата, копирование кода, переход к GitHub и успешная подписка.

Мы не передаём в события поисковые фразы, промпты, email, текст feedback, query string URL или рекламные идентификаторы. Advertising storage, ad-user-data и ad-personalization остаются отключёнными. Global Privacy Control и Do Not Track не дают загрузить GA.

## Реклама

На этой ветке нет рекламных скриптов и рекламных cookie. Одной аналитики недостаточно для персонализированной рекламы: если сайт когда-либо подключит publisher-рекламу для EEA/UK/Швейцарии, для неё потребуется отдельная сертифицированная CMP и отдельное уведомление.

## Полная политика

Полная каноническая политика пока доступна [на английском](https://happyin.space/privacy/). При расхождении юридически значимым остаётся английский текст до отдельной юридической проверки перевода.
