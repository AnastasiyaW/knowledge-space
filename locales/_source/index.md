# Happyin Knowledge Base

A technical reference for people who make engineering decisions and for AI agents that need verifiable source material. It does not promise one universal answer: every page states its version, where it applies and the real mistakes to check before you adopt it.

## Where to start

1. State the concrete result you need, not only the name of a technology.
2. Open the [task-first guide](start-here.md): it leads to the closest section and says what to check first.
3. Or open the [map of the knowledge base](knowledge-base/index.md) and the section you need.
4. If you work with an assistant, give it the page, the version of your environment and the result you need.

## Language and sources

The articles in this language are machine translations, checked automatically: code, commands, links and structure match the original. The English text is canonical, and every translated page links to it. A translation is updated when the original changes.

The language switcher in the header opens the same page in another language.
