# Happyin 知识库

这是一个面向工程决策者和 AI 智能体的技术参考库。每个材料都应包含版本、适用边界和需要在实际环境中验证的陷阱，而不是承诺一个放之四海而皆准的答案。

## 从哪里开始

1. 先描述明确的目标，而不只是技术名称。
2. 打开[按任务选择路径](start-here.md)，找到最接近的领域和首要验证项。
3. 大部分技术卡片目前仍提供[英文原文](https://happyin.space/knowledge-base/)。这是真实的原始资料链接，不会把英文页面伪装成中文翻译。
4. 与助手协作时，提供页面链接、环境版本和预期结果。

## 已完成翻译的内容

- 本入口和任务导航；
- [面向 AI 智能体的使用说明](for-llm-agents.md)；
- [隐私与分析说明](privacy.md)。

语言分支按已审核的页面逐步扩展：英文仍是技术内容的规范来源，机器草稿不等于可以发布的翻译。

## 语言与来源

页首语言选择器会进入真实的俄语或简体中文分支。若某项技术资料尚未翻译，链接会直接前往英文原文，不会在一个 URL 中混合两种语言。
