## Was es ist {#what-it-is}

ACTI ist eine mobile Tastatur für Menschen, die Suche, Übersetzung, Meeting-Links und verbundene Dienste ohne Wechsel zwischen Apps nutzen möchten. Funktionen: Halten der Acti Bar für eine Aktion, Zuordnung von Skills zu Tasten, Erstellung von Skills in natürlicher Sprache, private oder öffentliche Veröffentlichung im Skill Hub. Einschränkung: Der Start eines Skills übergibt nur den konfigurierten Eingabetext und kann auf KI-Anbieter oder verbundene Werkzeuge zugreifen. Fazit: geeignet für kurze, wiederholbare mobile Aktionen, erfordert aber, dass Zugriffe bewusst eingerichtet und Ergebnisse vor dem Absenden geprüft werden.

## Anwendung {#how-to-use-this}

Stand 2026-07-01 sollten Praktiker openacti.com und den verlinkten X-Download-Endpunkt als mögliche offizielle Zugangspunkte für ACTI behandeln. Vor dem Verlassen auf den Release- oder Download-Status sollte jedoch die ursprüngliche Ankündigung überprüft werden.

1. Installieren Sie Acti über die Download-Seite auf dem Telefon und aktivieren Sie die Tastatur in den Systemeinstellungen.
  — <https://openacti.com/dl/x>
2. Geben Sie in einem beliebigen Textfeld die Absicht ein und halten Sie anschließend die Acti Bar gedrückt, um die Aktion zu starten.
  — <https://openacti.com/>
3. Für eine wiederkehrende Aufgabe öffnen Sie den Skill Builder, beschreiben die Aktion in einfachen Worten und weisen den erstellten Skill einer Taste zu.
  — <https://openacti.com/acti-skill-hub/>
4. Prüfen Sie vor der Verbindung von Gmail, Slack, Notion oder einem anderen Dienst, welchen Eingabetext und welches Werkzeug der jeweilige Skill verwendet.
  — <https://openacti.com/privacy/>

## Bewährte Vorgehensweisen {#best-practices}

- Beginnen Sie mit privaten Skills und veröffentlichen Sie sie erst, nachdem Eingaben, verbundene Werkzeuge und Ergebnis geprüft wurden.
  — <https://openacti.com/acti-skill-hub/>
- Geben Sie sensible Texte nur bei Bedarf an einen Skill weiter: Beim Start können festgelegte Eingaben, Parameter und Daten übermittelt werden, die der KI-Anbieter oder das verbundene Werkzeug benötigt.
  — <https://openacti.com/privacy/>
- Behandeln Sie das Ergebnis eines Skills als Entwurf: Prüfen Sie insbesondere Links, Übersetzungen und Aktionen in externen Diensten, bevor Sie etwas absenden.
  — <https://techcrunch.com/2026/06/30/acti-puts-ai-agents-directly-into-your-smartphone-keyboard/>
