## Was es ist {#what-it-is}

Omma ist ein Produkt von Spline für Designer und Entwickler, die interaktive Web-Erlebnisse ohne getrennte Workflows für 3D, Code und Medien erstellen.

- Parallele Generierung von Code, Bildern und 3D
- Dateiimporte für CSV, JSON, DOC, GLB, GLTF und Medien
- Remixes von Community-Projekten
- Veröffentlichung mit eigenen Domains

Die kostenlose Stufe ist auf 50 Credits pro Monat und 20 Chat-Nachrichten begrenzt. Das Produkt eignet sich für schnelle interaktive Prototypen und veröffentlichte Web-Projekte, die Generierung erfordert jedoch eine Planung der Credits.

  — <https://omma.build/>
2. Beschreiben Sie die gewünschte Website, App, 3D-Szene, das Spiel oder die Präsentation in einfacher Sprache.
  — <https://omma.build/>
3. Laden Sie bei Bedarf Daten oder Assets hoch: CSV, JSON, DOC, GLB, OBJ, PNG, SVG, MP4 oder GLTF.

4. Bearbeiten Sie das Ergebnis iterativ und veröffentlichen Sie es anschließend. Eigene Domains sind in kostenpflichtigen Tarifen verfügbar.
