## Was es ist {#what-it-is}

Komi Store (zuvor GitHub Store) ist ein Kotlin-Multiplatform-Browser und Installer für Releases.

- Asset-Suche: findet Projekte mit installierbaren Assets.
- Paket-Downloads: lädt plattformpassende APK-, EXE-, DMG-, AppImage- und DEB-Pakete herunter.
- Update-Verfolgung: überwacht Releases und blockiert APKs, wenn sich der Android-Signaturschlüssel ändert.
