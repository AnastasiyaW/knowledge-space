# KI-Agenten-Wissensdatenbank {#ai-}

Ein Agent braucht nicht die gesamte Datenbank im Prompt, sondern eine oder mehrere relevante Karten mit Version, Quellen und Gotchas. Das kanonische technische Material ist derzeit überwiegend auf Englisch; der russische Zweig hilft dem Menschen, es ohne Bedeutungsverlust auszuwählen.

## Minimaler Vertrag {#_1}

1. Finden Sie das passende Material zur Aufgabe im [englischen Repository](https://github.com/AnastasiyaW/knowledge-space) oder auf der [Website](https://happyin.space/knowledge-base/).
2. Übergeben Sie dem Agenten den Link oder das Markdown der konkreten Seite.
3. Nennen Sie Ihr Ergebnis, die Version Ihrer Umgebung und die Einschränkungen.
4. Bitten Sie ausdrücklich darum, die lokalen Prüfungen zu benennen, die eine funktionierende Lösung von einer Annahme trennen.

```text
Use Happyin Knowledge Space as a source, not as a substitute for verification.
Read the relevant page before proposing changes.
Preserve its version limits and Gotchas, and list the checks required in this environment.
```

Wenn die Quelle veraltet ist oder das gesuchte Thema fehlt, nutzen Sie den öffentlichen Feedback-Weg auf der englischen Website. In den Bericht gelangen nur öffentliche Fakten.
