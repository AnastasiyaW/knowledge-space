# Schreiben {#writing}

Technisches Schreiben sollte belegbare Fakten erhalten und seinen beabsichtigten Leser dabei unterstützen, eine Aufgabe zu erledigen. Diese Sammlung behandelt Struktur, Klarheit, redaktionelle Prüfung und Veröffentlichung. Stilhinweise sind Anstöße zur Prüfung, keine Urteile über die Autorschaft; die Referenz zur Erkennung trennt die Korpusforschung von Belegen aus einzelnen Dokumenten.
